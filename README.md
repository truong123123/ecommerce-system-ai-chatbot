# StoreKit Enterprise Platform

Dự án Đồ án Tốt nghiệp / Ứng dụng Thương mại Điện tử Bán lẻ Thiết bị Công nghệ Chính hãng.

## Cấu trúc mã nguồn

my-store/
├── frontend/     # giao diện người dùng
├── backend/      # REST API
├── database/     # migration và seed
└── docs/         # tài liệu dự án

## Khởi chạy dự án

- Frontend: cd frontend && npm run dev
- Backend: cd backend && ./mvnw spring-boot:run
